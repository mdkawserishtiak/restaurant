# Bengali Feast

A modern restaurant landing page for a Bengali cuisine brand, built with vanilla JavaScript and bundled using Webpack. The app features a polished single-page experience with a dynamic navigation system, food highlights, and a warm premium aesthetic inspired by Bengali hospitality.

## Overview

This project showcases a fictional restaurant called Bengali Feast, highlighting:

- a hero section with signature cuisine messaging
- interactive navigation between Home, Menu, and About pages
- menu cards for popular Bengali dishes
- rich food photography and warm earthy branding
- responsive layout optimized for desktop and mobile devices

## Tech Stack

- JavaScript (ES modules)
- Webpack 5
- Tailwind CSS
- HTML templates
- Asset handling via image imports

## Features

- Dynamic page switching without a framework
- Reusable page modules for Home, Menu, and About sections
- Tailwind-based styling for a clean restaurant UI
- Responsive card layout and hero design
- Local image assets integrated directly into the front-end bundle

## Scripts

```bash
npm install
npm run dev
npm run build
```

### Available Scripts

- `npm run dev` — starts the webpack development server
- `npm run build` — builds the production bundle

## Running the Project

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Start the app in development mode:

```bash
npm run dev
```

4. Open the local development server URL shown in the terminal

## Production Build

To generate a production bundle:

```bash
npm run build
```

The output will be generated by Webpack and ready to deploy.

## Notes

This is a front-end project focused on visual presentation and interactive UI behavior. It is ideal for demonstrating how to build a modern restaurant landing page using a lightweight JavaScript setup without heavier frameworks.
